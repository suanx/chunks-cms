# 数据库文档

## 表结构

详见架构设计文档 `chunyu-cms-architecture.md` 中的数据库表结构设计章节。

## 主要表

- users - 用户表
- roles - 角色表
- user_roles - 用户角色关联表
- videos - 视频表
- movies - 影视剧表
- episodes - 剧集表
- categories - 分类表
- comments - 评论表
- favorites - 收藏表
- ratings - 评分表
- banners - 横幅表
- tags - 标签表
- actors - 影人表
- watch_history - 观看历史表
- upload_records - 上传记录表
